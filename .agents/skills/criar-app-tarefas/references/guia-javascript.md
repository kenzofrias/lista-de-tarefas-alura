# Padrões de Implementação JavaScript

Ao gerar o arquivo `src/script.js`, siga o padrão de código abaixo:

1. **Manipulação do DOM:**
   - Utilize métodos padrão como `document.getElementById` e `document.createElement`.

2. **Eventos:**
   - Mapeie os eventos usando `addEventListener`.

3. **Estrutura da Função:**
   - Mantenha a lógica de adicionar, concluir e remover em funções separadas com nomes claros.
